# Leopard Taxis

Single-page marketing website for Leopard Taxis — taxi and airport transfer services across Warwickshire and the West Midlands.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Booking
